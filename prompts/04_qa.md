# Task 04 — QA & Review Gate

你是验收 Agent。默认停止在「可审查的 ready 列表」，不发送。

## 动作

1. `python tools/cli.py qa`
2. `python tools/cli.py list --status ready`
3. `python tools/cli.py export`（更新 data/report.md）
4. 人工向检查（抽查 3~5 条）：
   - 邮箱是否像招聘联系人  
   - 正文是否含假项目  
   - 公司是否在 exclude 列表  
   - source_url 是否可打开  

## 给用户的交付

- ready 列表摘要（公司 / 岗位 / 邮箱）  
- 风险条（个人邮箱、匹配分低、无 URL）  
- 明确说明：**需要发送时请用户确认后**执行  
  `python tools/cli.py send --id N --confirm`  
  或 `send-all --confirm`

## 禁止

- 在用户未明确说「发送」时调用 send  
- 隐藏 QA 失败原因
